# 管理员测试角色工作台切换任务

## 目标

测试阶段为 `ADMIN` 提供四种角色工作台的只读预览能力；不改变登录身份、不改变权限、不允许预览态执行业务写操作。正式公司内网默认关闭，通过服务端配置显式开启。

## P0 契约与安全

- [ ] 固定 `WorkspaceViewRole`：`OPERATOR`、`MATERIAL`、`WAREHOUSE_ADMIN`、`ADMIN`。
- [ ] 增加 `ENABLE_ADMIN_ROLE_PREVIEW=false` 配置，缺失或非法值按关闭处理。
- [ ] `viewRole` 仅允许认证角色 `ADMIN`，其他角色返回 `403 ROLE_PREVIEW_ADMIN_ONLY`。
- [ ] 配置关闭时返回 `404 ROLE_PREVIEW_DISABLED`。
- [ ] 预览上下文不修改 token claims、用户角色、数据库 `users.role` 或权限缓存。
- [ ] 预览态所有写接口统一返回 `403 ROLE_PREVIEW_READ_ONLY`。
- [ ] 禁止在审计、响应或日志中写入 Token、密码、source_ip 和完整请求体。

## P0 后端

- [ ] 为 `GET /api/v1/workspace/summary` 增加可选 `viewRole`、`X-Client-Operation-Id` 和严格 UUID/requestId 校验。
- [ ] 为 `GET /api/v1/workspace/material-items` 增加同样的 `viewRole` 和审计上下文。
- [ ] 将现有角色过滤函数改为接收 `authenticatedRole` 与 `viewRole`，仅在 ADMIN 预览时使用 viewRole。
- [ ] 返回 `role`、`preview`、`authenticatedRole` 元数据，保证客户端可显示只读预览标识。
- [ ] 追加 `ADMIN_ROLE_PREVIEW` 审计事件，覆盖 `ENTER`、`QUERY`、`EXIT`。
- [ ] 新增回归测试：四视图摘要/列表、非 ADMIN 拒绝、开关关闭、非法角色、写接口拒绝、审计脱敏、重试不重复。

## P1 Android

- [ ] 在管理员工作台增加“测试角色视图”入口和四角色选择器。
- [ ] 仅 ADMIN 渲染入口；入口隐藏不是安全措施。
- [ ] 使用内存态 `WorkspaceQueryContext`，退出预览后恢复 ADMIN 视图。
- [ ] 预览页固定显示“测试预览，只读，不代表当前账号权限”。
- [ ] 预览态禁用领取、到工位、审批、出库、交接确认/驳回/取消按钮。
- [ ] 切换角色取消旧请求，仅保留当前角色分页 20 条；并发不超过 2。
- [ ] 进程重启、退出登录、refresh 失效后清除预览状态。
- [ ] 增加 ViewModel、解析器、Repository 和 UI 回归测试。

## P1 测试环境

- [ ] 当前测试阶段允许直接使用明文 HTTP 测试地址，无需 HTTPS；仅限 Debug 包和受控测试网络。
- [ ] 测试部署显式设置 `ENABLE_ADMIN_ROLE_PREVIEW=true`，不得写入 Git 或 APK。
- [ ] 测试用管理员账号使用脱敏密码管理，不在任务、日志或截图中暴露凭据。
- [ ] 测试只验证视图展示和只读过滤，不使用预览角色执行真实库存变更。
- [ ] 正式公司内网部署前将开关设为 `false`，除非安全评审明确批准保留。

## 验收门禁

- [ ] 后端相关测试和全套契约测试通过。
- [ ] Android JVM 单测和 Debug 构建通过。
- [ ] `git diff --check` 通过。
- [ ] 变更范围仅包含源码、测试、docs/tasks，不包含数据库、APK、日志、环境文件和凭据。
- [ ] 测试报告明确区分自动化验证、测试环境接口验证和实体真机验收。
