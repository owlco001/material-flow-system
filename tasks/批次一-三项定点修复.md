## 项 1（后端，S）协作装配成员打开订单详情报 403

**现象**：一台机由多人协作（`assembly_task_members` 表）时，非 LEAD 成员点订单详情/任务，后端按 `assigned_assembler_id` 判权 → 403，装配任务无法继续。

**证据**
- 缺陷点：`material-flow-backend/app/main.py` 第 4233 行、4242 行，范围条件只查 `assigned_assembler_id`
- 数据模型：`assembly_task_members` 建表见 `main.py:782`
- 正确判权写法参考：`app/assembly_routes.py:11-13`

**验收**
1. 作为该任务 `assembly_task_members` 中的非 LEAD 成员请求订单详情/任务 → **200**，payload 与 LEAD 一致（可见范围不放大：仍只返回其参与的任务）
2. 非成员 → 仍 403
3. 新增 pytest 覆盖：成员通过 / 非成员 403 / LEAD 不回归
4. 不得放宽其他任何判权路径（禁止全局把 `assigned_assembler_id` 判断删掉）

**证据**

- 已有正确范式：同文件 `:820` 对 RETURN / RELOCATION 从 `remark` JSON 解出

**验收**
