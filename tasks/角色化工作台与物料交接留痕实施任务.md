# 角色化工作台与交接留痕任务修订项

## P0 契约冻结

- [ ] 以 `docs/V1角色与枚举契约冻结决议.md` 为唯一角色、订单类型、扫码类型规范。
- [ ] 统一状态域与转换，按 `docs/V1状态与状态映射规范.md` 补齐服务端字段。
- [ ] 按 `docs/V1交接与审批契约.md` 补充 `transferRequestId` 和确认/驳回/取消幂等键。
- [ ] 按 `docs/V1审计与留痕字段规范.md` 明确 `audit_logs` 与 `audit_events` 边界。

## P0 后端垂直切片

- [ ] 角色字段改为受限枚举；历史 `MATERIAL_CLERK` 迁移为 `MATERIAL`。
- [ ] 订单类型只接受 `PRODUCTION_ORDER`，旧 `ORDER_NO` 测试改为 400。
- [ ] 新增工作项投影、交接表、只追加审计事件表和迁移脚本。
- [ ] 实现工作台汇总/分页工作项/交接创建/确认/驳回/取消/时间线 API。
- [ ] 创建交接不扣库存；审批通过后的出库执行才扣库存；所有业务变更和审计同事务。
- [ ] 对所有查询增加角色、订单、机台、责任人过滤；禁止普通角色读取全局申请。

## P1 Android

- [ ] 修复冷启动 token 恢复后 UI 仍停留登录页的问题，加入 `Restoring/Authenticated/Unauthenticated` 状态。
- [ ] 持久化用户摘要、角色和稳定 deviceId；refresh 失效事件统一回登录页。
- [ ] 按角色接入工作台：操作员看已领取/已到机台，物料员看待出库/已出库，仓管看审批/交接，管理员看全量/审计。
- [ ] 订单机台物料详情增加交接时间线、当前责任人和服务端时间。
- [ ] 交接创建支持离线队列和幂等重放；确认/驳回/取消默认只在线执行。

## 验收门禁

- [ ] 契约冲突组合全部有旧值拒绝、新值成功测试。
- [ ] 四角色越权、审批前库存不变、状态机终态、并发版本冲突全部通过。
- [ ] 同幂等键重试不重复扣库存、不重复审计。
- [ ] 交接时间线字段完整且敏感字段脱敏。
- [ ] Android 冷启动、退出、refresh 失效、弱网分页、8GB 中端设备验证通过。
