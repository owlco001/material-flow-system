# 厂内物料流转 V1 实施任务清单（修正版）

> 本清单以“生产订单—细分机型—物料—厂内库位流转”为唯一业务口径；不包含外部物流、线边库或配送工位。架构 Agent 只维护 `docs/` 与 `tasks/` 文档，不直接修改业务源码。

## P0：统一领域模型

- [ ] 生产订单主表：订单号、产品名称、计划数量、交期、生产状态、创建/更新时间。
- [ ] 生产订单机型表：订单关联、机型编码、机型名称、计划数量、状态。
- [ ] 机型物料需求表：料号、需求数量、已到料、已入库、已领料、可用库存、差额。
- [ ] 厂内库位表：库位编码、名称、类型、启用状态；不建立线边库或工位实体。
- [ ] 厂内流转记录表：流转单号、订单、机型、料号、来源库位、目标库位、数量、类型、状态、操作人、服务端时间。
- [ ] 图片凭证关联表：库位、异常、入库、出库或流转记录关联文件。

## P0：扫码与查询

- [ ] 扫码类型统一为 `PRODUCTION_ORDER`、`MATERIAL_CODE`、`LOCATION_CODE`、`FLOW_NO`、`UNKNOWN`。
- [ ] 生产订单扫码返回订单概览、机型列表、物料齐套率和最近厂内流转时间。
- [ ] 点击机型返回物料需求、库存分布和厂内流转记录。
- [ ] 料号扫码返回物料详情、批次/规格/有效期扩展字段、库存和库位分布。
- [ ] 库位码扫码返回该库位物料清单和最近流转记录。
- [ ] 流转单号扫码返回该次厂内流转详情。

## P0：库存与审批

- [ ] 入库申请：创建、提交、审批、执行；审批前不得变更库存。
- [ ] 出库/领料申请：创建、提交、审批、执行；执行前校验可用库存和版本号。
- [ ] 厂内库位调拨：来源库位扣减、目标库位增加，事务内完成并记录审计。
- [ ] 退料：形成独立厂内流转记录，按入库规则处理。
- [ ] 盘点：物料员提交实盘数量，仓库管理员确认差异。
- [ ] 异常库存调整：必须进入审批流程。
- [ ] 所有数量只允许整数；拒绝小数、负数、零数量操作和负库存结果。

## P1：订单与机型页面

- [ ] 生产订单列表：支持订单号、产品名称、订单状态和交期筛选。
- [ ] 生产订单详情：展示机型列表、齐套率、缺料数、厂内流转统计。
- [ ] 机型详情：展示物料状态、数量差额、库位分布、流转时间线。
- [ ] 状态由服务端返回枚举、文字、颜色 token 和图标语义；客户端不自行推导核心状态。
- [ ] 移除“物流情况”“物流轨迹”“承运商”“运输中”“配送工位”“线边库”等页面字段和文案。

## P1：管理与审计

- [ ] 管理员用户管理：用户、角色、启用状态和最后登录时间。
- [ ] 审批列表：按待审批、已通过、已拒绝、已执行筛选。
- [ ] 审计日志：记录操作者、角色、IP、设备 ID、请求 ID、前后状态和服务端时间。
- [ ] 图片上传：限制 JPEG/PNG/WebP、单张不超过 5MB、随机文件名并绑定业务记录。

## 验收标准

1. 任意接口、数据库表、页面文案不得新增外部物流字段。
2. 生产订单可以关联多个细分机型；机型可以关联多个物料需求。
3. 查询生产订单必须能够进入机型详情并看到厂内流转记录。
4. 任意库存变化均可追溯到厂内流转记录、操作者和服务端时间。
5. 入库、出库审批未通过时，库存数量保持不变。
6. 调拨失败、版本冲突或库存不足时，整个事务回滚。
7. APP 联调包本轮不构建；后续完成接口实现后再统一联调。
