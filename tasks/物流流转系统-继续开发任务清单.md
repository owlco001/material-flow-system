# 物流流转系统继续开发任务清单

更新时间：2026-09-15
适用分支：`feature/t001-coherence`
范围：开发 Agent 修改 `logistics-android/` 与 `material-flow-backend/`；架构 Agent 仅维护本任务文档。
契约依据：`docs/物料流转系统-V1-API契约冻结补遗.md` 覆盖旧文档中的冲突示例。
摄像头扫码依据：`docs/物流流转系统-Android摄像头扫码实现规格.md`。

## P0-A：先修契约和安全

- [ ] A01 统一扫码枚举：后端和 Android 使用 `PRODUCTION_ORDER`、`FLOW_NO`、`MATERIAL_CODE`、`LOCATION_CODE`、`UNKNOWN`；删除运行时 `ORDER_NO`、`LOGISTICS_NO`。
  - 验收：每个枚举有 API 测试；生产订单请求发送 `PRODUCTION_ORDER`；旧值返回 400。
- [ ] A02 移除 Android 硬编码 API 地址。
  - 验收：地址只来自 `BuildConfig.API_BASE_URL` 或构建参数；Release 禁止 HTTP；敏感信息扫描无地址泄露。
- [ ] A03 完成后端会话生命周期。
  - 范围：Argon2id、refresh token 哈希存储、刷新、退出、过期、连续 5 次失败锁定 15 分钟。
  - 验收：登录/刷新/退出/锁定自动化测试通过；响应不记录密码和 token。
- [ ] A04 修复库存乐观锁和事务。
  - 范围：执行请求必须携带并校验 `expectedInventoryVersion`；库存版本不匹配返回 409；同步更新物料汇总和库位明细；同一 requestId 重试不得重复扣减。
  - 验收：并发冲突不会改变库存；重复执行不会重复扣减。
- [ ] A05 强制审批与执行同人隔离。
  - 验收：审批人不能执行同一单据；管理员和仓库管理员权限边界有测试；所有动作有 requestId/traceId 审计。

## P0-B：Android 工程分层和真实持久化

- [ ] B01 将 `MainActivity.kt` 拆为 `presentation/domain/data/platform` 分层。
  - 验收：Composable 不直接调用 HTTP、JSON 或数据库；ViewModel 只暴露 `StateFlow<UiState>` 和事件入口。
- [ ] B02 接入 Retrofit、kotlinx.serialization、统一 DTO 和错误模型。
  - 验收：网络错误可区分 401、409、4xx、5xx、超时；错误模型包含 `code`、`retryable`、`traceId`。
- [ ] B03 配置 Room compiler/KSP，完善 `offline_operations`。
  - 必备字段：唯一 `clientOperationId`、加密 payload、状态、重试次数、错误码、时间戳；按状态/时间分页。
  - 验收：Room schema 编译成功；重复 operation ID 不产生第二条记录；进程重启后数据仍存在。
- [ ] B04 接入安全会话存储。
  - 验收：access/refresh token 不写普通明文偏好存储、不进入日志；退出后本地 token 清理。
- [ ] B05 实现 WorkManager 同步状态机。
  - 约束：每批最多 20 条、并发 2、自动重试最多 5 次；固定 `clientOperationId`；409 进入 `CONFLICT`。
  - 验收：断网入队、恢复网络自动同步、重复触发不重复建单。

## P1：核心业务闭环

- [ ] C01 实现登录、角色导航和服务端权限拦截。
- [ ] C02 实现扫码适配层：CameraX、ML Kit、手动输入、工业扫码枪键盘楔入/广播适配接口、1500ms 去重窗口；按摄像头扫码实现规格交付权限拒绝降级和生命周期释放。
- [ ] C03 实现生产订单扫码→物料状态列表→物料详情。
- [ ] C04 实现入库、出库、调拨、盘点四类流转；数量仅正整数且禁止负库存。
- [ ] C05 实现物料码+库位码双扫和库位绑定。
- [ ] C06 实现异常单、图片压缩上传和凭证关联；单图最长边 1920px、2MB 内、最多 5 张。
- [ ] C07 将打印做成独立任务；库存提交成功不依赖打印成功，支持失败重打。
