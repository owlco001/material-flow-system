# 物料流转系统后端部署任务

## M0：业务和接口冻结

- [ ] 确认物料编码、批次、单位、有效期和库存维度
- [ ] 确认库位编码和条码格式
- [ ] 确认入库、出库、调拨、盘点审批规则
- [ ] 确认内部用户来源和初始管理员
- [ ] 确认 APP 访问范围：公网 HTTPS、公司 VPN 或 IP 白名单

## M1：VPS 后端基础

- [ ] 创建独立部署目录 `/srv/material-flow`
- [ ] 创建非 root 运行用户 `material-flow`
- [ ] 创建 Python 虚拟环境
- [ ] 部署 FastAPI + Uvicorn
- [ ] SQLite 开启 WAL、外键约束和定期备份
- [ ] systemd 管理 API 进程，失败自动重启
- [ ] API 只绑定 `127.0.0.1:8000`
- [ ] 在业务确认后配置 HTTPS 反向代理

## M3：安全和运维

- [ ] JWT/会话密钥通过环境文件注入，不进入 Git
- [ ] 密码使用 Argon2id 哈希
- [ ] 限流、请求体上限、上传文件类型和大小限制
- [ ] 每日数据库备份并验证可恢复
- [ ] systemd 日志和应用审计日志脱敏
- [ ] 迁移已暴露的 SSH、面板、API 和 DNS 凭据

## 开发阻塞

后端代码可以按 Mock/默认业务规则启动，但生产部署前必须获得：业务字段、审批规则、登录方式、初始管理员和访问范围。
