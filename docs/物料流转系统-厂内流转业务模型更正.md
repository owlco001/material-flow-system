# 物料流转系统业务模型更正：厂内流转

## 需求更正

本系统不对接外部物流，也不展示承运商、运输轨迹或物流节点。此前“物流号/物流情况/物流轨迹”的描述全部作废。

正确业务范围是：**公司内部生产订单关联厂内物料流转信息**。

## 正确业务层级

```text
生产订单
└── 细分机型
    └── 物料需求
        └── 厂内物料流转记录
            ├── 收货/到料登记
            ├── 厂内入库
            ├── 库位绑定
            ├── 领料/出库申请
            ├── 退料
            ├── 厂内调拨
            ├── 盘点
            └── 异常及图片凭证
```

## 生产订单详情

订单详情展示：

- 生产订单号
- 产品名称
- 机型列表
- 计划数量、交期、订单状态
- 物料齐套率
- 缺料数量
- 最近厂内流转时间

点击机型后展示：

### 物料需求状态

- 需求数量
- 到料数量
- 已入库数量
- 已领料数量
- 厂内可用库存数量
- 当前可用库存
- 缺口数量
- 红/黄/绿状态

### 厂内流转状态

- `待到料`
- `已到料`
- `待入库`
- `已入库`
- `待领料`
- `已领料`
- `厂内调拨中`
- `已退料`
- `异常`

每条流转记录包含：操作类型、来源位置、目标位置、数量、操作人、服务端时间戳、关联订单、机型、料号和图片凭证。

## 状态计算

### 物料状态

- 红色 `SHORTAGE`：可用库存 + 已到料未入库数量小于需求数量，且没有可直接使用的厂内库存。
- 黄色 `IN_PROCESS`：已到料、待入库、待领料、调拨中或部分满足需求。
- 绿色 `AVAILABLE`：可用库存满足该机型需求。

### 机型状态

- `SHORTAGE`：存在缺料物料
- `INTERNAL_PROCESSING`：物料正在厂内收货、入库、领料或调拨
- `READY`：物料齐套，可投产
- `IN_PRODUCTION`：生产中
- `COMPLETED`：完成

服务端返回状态枚举、中文标签、颜色 token、图标语义和数量字段，客户端不自行推导核心状态。

## 扫码规则

支持扫描：

- 生产订单号
- 料号
- 库位码
- 流转单号

不再支持或定义“物流号”。

扫码生产订单号后进入订单详情；点击机型进入厂内物料流转详情；点击流转记录查看完整厂内路径。

## API 修正

- `POST /api/v1/scan/resolve`：识别 `PRODUCTION_ORDER`、`MATERIAL_CODE`、`LOCATION_CODE`、`FLOW_RECORD`。
- `GET /api/v1/production-orders`：生产订单列表。
- `GET /api/v1/production-orders/{orderNo}`：订单及机型汇总。
- `GET /api/v1/production-orders/{orderNo}/models/{modelCode}`：机型物料与厂内流转详情。
- `GET /api/v1/production-orders/{orderNo}/models/{modelCode}/flow-records`：厂内流转记录。
- `GET /api/v1/materials/{materialCode}/inventory`：料号库存及库位。
- `POST /api/v1/transfer-requests`：入库/出库申请。
- `POST /api/v1/relocations`：厂内库位之间调拨。
- `POST /api/v1/location-bindings`：物料与库位绑定。
- `POST /api/v1/files`：库位、异常、流转图片凭证。

以下接口和概念删除：

- `/api/v1/logistics/{logisticsNo}/tracking`
- `logistics_shipments`
- `shipment_items`
- `logistics_tracking_nodes`
- 承运商、发货地、目的地、预计到达、物流节点

## 数据库修正

保留/新增：

- `production_orders`
- `production_models`
- `model_material_requirements`
- `material_flow_records`
- `material_locations`

- `flow_record_evidence`

`material_flow_records` 字段：

- `id`
- `flow_no`
- `production_order_id`
- `model_id`
- `material_id`
- `flow_type`
- `source_location_id`
- `target_location_id`
- `quantity`（非负整数）
- `status`
- `operator_id`
- `remark`
- `created_at`（服务端时间戳）

## 审批规则

- 厂内入库、出库/领料：需要审批。
- 厂内调拨、库位绑定：简化流程，但必须记录操作和时间戳。
- 盘点：物料员提交，仓库管理员确认差异。
- 异常库存调整：需要仓库管理员或管理员审批。

## 影响范围

此前所有外部物流相关文档描述应以本文件为准。后端和 APP 后续开发统一使用“厂内流转”语义，不创建外部物流、线边库或配送工位模块。
